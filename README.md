# Sales Data Analysis Using Excel and Power BI

## Project Overview

This project explores sales transaction data using Microsoft Excel and Power BI. The aim is to analyse sales performance across different regions and product categories and present the findings in a clear, visual format.

## Objectives

- Analyse total sales across different regions.
- Compare sales performance across product categories.
- Explore transaction patterns over time.
- Use data visualisation to communicate business insights.
- Develop practical skills in data analysis and dashboard reporting.

## Tools Used

- **Microsoft Excel:** Pivot tables, frequency distributions, data analysis and visualisation.
- **Microsoft Power BI:** Sales visualisation and dashboard reporting.

## Dataset

The dataset contains 2,000 sales records, including transaction dates, customer demographics, product categories, units sold, payment methods, regions and total sales.

## Analysis Performed

- Sales comparison by region.
- Sales comparison by product category.
- Monthly transaction analysis.
- Frequency distribution of total sales.
- Visual presentation of sales information.

## Analysis Summary

The project involved analysing sales transaction data to explore:

- Differences in sales performance across regions.
- Sales patterns across product categories.
- Monthly transaction trends.
- The distribution of transaction values.

The analysis used Excel tools to organise, summarise and visualise data, with Power BI included in the project workflow.
